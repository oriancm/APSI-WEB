# APSI BTP — Propositions de design

Ouvrir `index.html` pour comparer les huit propositions (deux par page) et retrouver les captures du site actuel.

## Captures

Les huit pages principales ont été capturées depuis http://127.0.0.1:8088 avec une fenêtre de 1400 × 720 pixels, à l’échelle 1. Une capture de toute la hauteur de chaque page est également disponible. Les réponses HTTP étaient toutes 200. Voir `captures/manifest.json`.

Références validées : accueil, Qui sommes-nous, Nos métiers, Nos références.

## Propositions

- Nos clients : A, bandeau diagonal et mur de logos ; B, répertoire avec navigation latérale.
- Nous contacter : A, carte de formulaire blanche sur le visuel ; B, photo et formulaire en deux colonnes.
- Mentions légales : A, deux cartes ; B, sommaire latéral et informations structurées.
- Politique de confidentialité : A, quatre cartes ; B, sections de lecture numérotées.

Maquettes générées avec l’outil intégré ImageGen, en prenant directement les quatre captures validées et la capture de la page concernée comme références. Les instructions complètes sont conservées dans `prompts.json`.

Ces propositions sont des images, pas des pages intégrées. À l’intégration, reprendre les logos et les textes depuis les fichiers originaux du site pour garantir leur fidélité. Les fichiers du site existant n’ont pas été modifiés par ce travail.
